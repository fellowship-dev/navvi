# Navvi

Prompt in, data out, and the second run costs nothing.

Navvi v3 is a self-healing scraper compiler. Describe what you want from a
site, give it a few URLs, and it navigates, compiles one scraper per page
template, and replays it on selectors with no model call. When the site
drifts, it heals the broken field or step and keeps going.

Work in progress. The plan lives in the Fellowship workspace; the first
release is the local CLI.
